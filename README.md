## ✨ 功能特色

- ✅ **LINE LIFF 整合**：自動讀取用戶資料
- ✅ **Google Calendar API**：自動加入韓哥行事曆
- ✅ **iOS/Android 支援**：智能偵測並提供專屬日曆連結

## 📍 預約流程

1. 客戶在 LINE 中點擊預約連結
2. LIFF 打開預約表單，自動填入姓名
3. 選擇日期、時間、服務項目
4. 點擊「立即預約」
5. 自動呼叫 Google Calendar API 加入韓哥行事曆
6. 發送 Flex Message 確認訊息給客戶
7. 客戶可一鍵加入自己的日曆（iOS .ics / Android Google Calendar）
